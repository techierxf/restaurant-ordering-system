# Restaurant Ordering System

A console-based Restaurant Ordering System developed using Java and MySQL. 
The system allows users to view food items, update food information, delete food items, and place orders.

## Features

- View Food
- Update Food
- Delete Food
- Order Food
- Food Categories
  - Main Course
  - Appetizer
  - Drinks
  - Dessert
- Calculate Order Total
- Checkout and Payment
- Calculate Change
- Manage Food Stock
- MySQL Database Integration

## Technologies Used

- Java
- MySQL
- XAMPP
- phpMyAdmin
- NetBeans
- JDBC

## Database

Database Name:

`restaurant_db`

Table:

`foods`

### Food Table Fields

| Field | Description |
|---|---|
| food_id | Unique ID of the food |
| food_name | Name of the food |
| price | Price of the food |
| quantity | Available stock |
| category | Food category |
